## 2. 算法口径（最终生效）

**隐患一**：`g_q < 0`（单季扣非同比为负，口径 = `fund_detail.modeB.g_q` 唯一来源）→ 最终 `score_growth ≤ 4.0`。
- 作用点在**全池百分位之后**（旧 `gq_neg_cap_0.4` 只压中间 composite，治显示不治排序）。
- 不误伤：`g_q` 缺失 / 负基数(None) / 非数值不触发；已 ≤4 不动；cagr3 弱锚由既有 anchor_gate 处理，不重复。

**隐患二**：命中增速恶化（`g_q<0` 或 `qoq<−20%`）→ `score_ep = max(6.0, ep_raw − 2.0)`，保留区分度。
- 本季亏损（`q_profit<0`）→ 仍硬封顶 6.0（真变脸票不豁免）。
- 龙头豁免（`mode="exempt"`，质量≥8/非周期/现金流正）**未启用**：质量分做 gate 有内生性/循环论证风险，待 walkforward。

**隐患三**：`--per-sector 3→2`，`--per-parent 2` 与 L1 偏离 8pp 不变；展示层 `TOP_SECTOR_CAP=2` 同口径。
