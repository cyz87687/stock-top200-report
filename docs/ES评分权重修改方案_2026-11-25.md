> 决策人：老大｜证据基线：`top200_scored_2026-11-24.json`（1798 只）、`data/fin_cache_em/`、`data/q3_forecast_2026-10-14.json`、`data/klines_long.json`

> 纪律：跨权重版本 `total` 禁比；禁称「经验证的 alpha」；缺维剔分母、禁 `or 0`；单一实现

## 一、问题定性：ES 是「名义 5%、实际 0」的死维

| 事实 | 数值 | 出处 |
|---|---|---|
| ES 名义权重 | 5%（`factor_weights.json` weights.score_es） | 权重表 |
| 实际生效权重 | **0**（运行时按比例让渡给其余七维） | `scale_calc.effective_weights_es_gate` |
| 触发原因 | 全池有效覆盖 57/1798 = **3.17%** < 门槛 30% | `apply_sector_momentum.py:211-217` |
| 覆盖来源 | 机构 Q3 预测表仅 105 条（在池 81，判定有效 57） | `data/q3_forecast_2026-10-14.json` |
| 实际后果 | 三只超预期样本（中科飞测/华海清科/长电科技，score_es=10）对总分贡献 0 | 复算：35.72→32.34 / 49.28→46.61 / 52.34→49.83 |

**定性：口径债，不是数据缺失。** 权重表写 5%、运行时归零、页面披露「名义 5%、覆盖<30% 让渡」——同一件事三套表述，且该维实际从未对排序产生任何影响。

### 1.1 现有 ES 口径（预测差）判别力弱

| 分组（n=49 有效样本） | 中位总分 | 中位单季同比 | 中位加速度 |
|---|---|---|---|
| 超预期（n=17） | 62.0 | **+262%** | +220pp |
| 符合预期（n=16） | 62.8 | +8% | +3pp |
| 低于预期（n=16） | 58.7 | +124% | +14pp |

超预期组与符合预期组中位总分几乎相同（62.0 vs 62.8）；超预期组中位单季同比 262% 说明**命中主要由低基数暴增主导**，而非「超出机构预期」本身。

### 1.2 前瞻检验（可得窗口 h=5/10，h=20 数据不足）

| 因子 | 截面数 | 平均 IC | t | 置换检验 p |
|---|---|---|---|---|

- 原 ES 口径：n≈63/截面，**远低于 194 的 IC 截面中位门槛 → 禁作权重依据**。
- 动能口径：n≈1100/截面（功效充足），方向为正但**不显著**（t=1.06 / 0.77）。**未证伪 ≠ 已验证**。

## 二、三个可选方案

### 方案 A：显式归零 + 权重回收（推荐先落）

| 项 | 变更 |
|---|---|
| `score_es` | 0.05 → **0**（从生效权重表移出，转 `pending_dims`） |
| `score_ep` | 0.15 → **0.20**（唯一合法回收去处） |
| `score_fund` | 0.15 **维持**（11-24 已结案「fund 不降权」） |
| 其余 | 不变（size_comb .20 / growth .20 / quality .15 / bias60 .05 / rsi_rev .05） |
| Σ | 1.00 ✓ |

**回收去处为何只有 ep**（`weight_constraints`：dim_cap 0.20、group_cap 0.30）：

| 大类 | 构成 | 合计 | 余量 | 可否加 |
|---|---|---|---|---|
| 基本面 | fund .15 + quality .15 | .30 | 0 | ✗（且 fund 禁降） |
| 估值 | ep .15 | .15 | .15 | ✓ → 加到 .20（dim_cap 上限） |
| 市值 | size_comb .20 | .20 | 0 | ✗（dim_cap 上限） |
| 业绩动量 | growth .20 | .20 | 0 | ✗（dim_cap 上限） |
| 技术反转 | bias60 .05 + rsi_rev .05 | .10 | .20 | ✓（备选） |

**代价**：估值维产品裁决加权（ep .15→.20），非 IC 背书，需重走 `weight_admission_gate`；`total` 全池变化 → 跨版本禁比公告。

**收益**：权重表 = 实际生效权重（无「名义/实际」两套口径）；ES 从死维变研究项，披露改为「未启用（附启用门槛）」。

### 方案 B：换口径为全池业绩动能（若老大要 ES 留在模型里）

口径定义（唯一实现建议放 `earnings_surprise.py` 同模块 `momentum_score()`）：

```
Δ加速度 = 单季归母同比 G_q(Q3) − 单季归母同比 G_q(H1)
G_q(t) = (累计 t − 累计 t−1期) / (去年同期 t − 去年同期 t−1期) − 1
归一   = 1%/99% Winsorize → 申万一级行业内百分位 rank → ×10
覆盖   = 1283/1798 = 71.4%（负基数 515 只 → 缺维）
```

关键实证支撑：

| 检验项 | 结果 | 判定 |
|---|---|---|
| 覆盖率 | 71.4% ≫ 30% 门槛 | ✅ 门控不再触发，5% 真正生效 |
| 与既有维秩相关（防重复计价） | growth .066 / quality .003 / ep .070 / **fund .236** / total .088 | ✅ 远低于 0.4（fund 最高，因 fund 维也用单季 G_q） |
| 极端票占比 | 单季同比 >300%：112 只（8.7%） | ⚠️ 需低基数饱和（复用 `growth_factor_b.lowbase_growth_cap` 既有做法） |
| 落地影响（复算，偏差 0.0000） | 排名 \|Δ\| 中位 6、最大 ±100；Top50 换入 **中科曙光、唯科科技**，换出 **胜宏科技、商络电子**；中位分 42.83→43.23、max 90.46→89.59 | 可控 |
| 预测力 | h=5 IC +0.019（t=1.06）、h=10 +0.024（t=0.77） | ⚠️ **不显著，未验证** |

**负基数的缺维归类（必须裁决）**：负基数 = 增速无定义，**不是业绩差** → 判 `structural`（分子分母同剔），禁按 `zero` 罚 0.5 分；若按 zero 则 515 只被系统性压低。

**代价**：口径变更 → 全池 total 重算 + 跨版本禁比公告；且该口径同样**未通过预测力检验**。

### 方案 C：A 立即执行 + B 待证据（推荐组合）

1. **本周落方案 A**：清口径债（改动小、可审计），ES 转 `pending_dims` 并在主页披露「未启用 + 启用门槛」。
2. **并行补 ES 证据**（不阻塞 A）：扩机构预测源 / 建 h=20 面板 / 动能口径 h=20 IC 检验。
3. 证据达标后按方案 B 重新启用 5% 权重（届时 growth+es=.25 < group_cap .30，权重空间仍在）。
