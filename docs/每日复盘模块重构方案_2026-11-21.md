## 一、截图信息结构解析

### 1.1 信息层级（四层）

| 层级 | 模块 | 字段内容 | 表达手法 |
|---|---|---|---|
| L0 元信息 | 基准行 | 生成时间、上证/创业板/科创50/北证50 涨跌、成交额、涨跌家数、涨跌停、中位数、两融余额 | 单行紧凑，关键数值加粗 |
| L1 一级① | 情绪周期定调（战略层） | 情绪坐标（冰点二次探底）、内盘证据（上涨家数/跌停/新低/晋级率）、外盘冲击（美股/日韩/导火索）、归因链 | `##` 标题 + `###` 子标题 + 多级项目符号 |
| L1 一级①-2 | 仓位与纪律红线 | 总仓位上限区间、三条铁律（禁打板/禁追高/禁浮亏加仓） | 结论前置 + 编号铁律 |
| L1 一级② | 核心消息与研报拆解 | 宏观地缘、事件日历（LPR/季检）、研报要点（营收/净利/CapEx） | 主题分组 + 数据括号标注来源 |

### 1.2 模块划分逻辑

- **事实层**（基准行）→ **解释层**（情绪定调）→ **动作层**（仓位纪律）→ **补充层**（消息研报）
- 情绪定调内部再分：内盘（自身情绪）→ 外盘（外部环境）→ 导火索（因果归因）
- 阅读路径：**先结论、后证据、再动作**，因果链显式（"因为 X → 所以 Y"）

### 1.3 可迁移的表达手法（不需新数据即可用）

1. 层级标题（`##` / `###`）建立视觉锚点
2. 关键数值 `<b>` 加粗，变化幅度带符号（+/−）
3. 括号标注来源/口径/时间（如"(前日 +1.61%)"）
4. 分组项目符号，组内并列、组间递进
5. 因果链句式（导火索 → 结果）

## 四、重构后的模块结构（目标形态）

复盘卡 `#sec-summary` 内部替换为四层，其余区块位置不变：

```
#sec-summary 每日复盘中心
├─ L0 基准行（chip 一行，源自 market_review；日期守卫生效）
│    [生成时间] [上证 -1.23%] [成交 1.43万亿] [涨297/跌4897 涨停28/跌停57] [两融 -154.89亿(PandaData)]
├─ L1① 情绪定调
│    结论句（money_score + money_phase 前置加粗）
│    ├ 内盘证据（涨跌/涨跌停/题材强弱 hot/weak）
│    ├ 资金证据（两融余额，PandaData get_margin）
│    └ 外盘与导火索（未接入占位，或 WebSearch 带来源时间戳）
├─ L1①-2 仓位与纪律
│    敞口上限（Hero 同口径，单一值） + 三条真实纪律（高分≠买入/方向不可预测/T+1T0不可实盘）
└─ L1② 消息与研报（details 折叠）
     ├ 关注方向（watch_directions，有源）
     ├ 事件日历（PandaData 财报事件 / 未接入占位）
     └ 研报拆解（local-review 链路 / 未接入占位）
     [来源徽标 + "禁称经验证的 alpha" 声明 + 五条可信度 → 保留不迁]
```

### 模块数据关系与交互逻辑

- **单向依赖**：L0 事实 → L1① 情绪（由 L0 的广度/两融推导）→ L1①-2 仓位（由 L1① 经 POSITION_LADDER + regime 取小）→ L1② 消息（旁路补充，不参与仓位计算）
- **日期一致性**：全卡共用 scored 的 `date`，任一子块数据日期≠当日用 `regime_date_guard` 判据隐藏该块，不显示陈旧值
- **来源标注**：每个 chip/结论带来源 tooltip（market_review / PandaData.get_margin / local-review / WebSearch+URL）
- **交互**：四层同屏顺序展开；L1② 长文用 `<details>` 折叠；来源徽标 hover 显示 tip；无数据源字段显示灰色"未接入"标签（不可点击、不误导）
