## 隐患一｜成长封顶失效（g_q<0 仍拿成长高分）

### 根因（代码级确认）

`growth_factor_b.compute_growth` 中 `gq_neg_cap_0.4`（单季增速为负→原始 composite 封顶 0.4）
作用于**全池百分位之前**的中间 composite；最终 `score_growth = _mid_rank_pct(composite)/10`，
即封顶只压低输入排名，无法约束输出绝对分。源码 `anchor_gate` 注释第 406 行已自认
「封顶治显示不治排序」。实证：全池 77 只、Top50 4 只 `g_q<0` 但成长分≥6
（振华股份 growth−5.2/g_q−0.316→8.0、涛涛车业 g_q−0.009→9.41、吉比特 g_q−0.15→8.87）。

**关键澄清**：`anchor_gate`(cagr3 门槛)、`lowbase_growth_cap`(低基数)、`cyclic_caps`(周期股)
三个封顶**已作用于最终分**（step2:5397/5401、enhance:324/326、apply_sector:284 双装），
缺的只是「g_q<0 → 最终成长分硬上限」这一条。

### 方案：新增最终分封顶函数 `gq_neg_final_cap`（单一实现）

| 项 | 内容 |
|---|---|
| 判据 | `g_q < 0`（单季扣非同比为负，来自 `fund_detail.modeB.g_q` 唯一来源）→ `score_growth ≤ 4.0` |
| 唯一实现 | `growth_factor_b.gq_neg_final_cap(score, g_q, cap=4.0)`，返回 (score_after, note) |
| 双装点 | ①`step2_stockscorer_v2.py` 约 5397（与 anchor_gate 同处）；②`enhance_scores.py` 约 324（回写覆盖点）；两处都调，**不可只装一处**（round17/2026-11-05 教训） |
| 不误伤 | `g_q` 缺失/负基数(None) 不触发（`neg_base_neutral` 哲学）；已 ≤4 不动；cagr3 弱锚票由既有 anchor_gate 处理，本函数不重复 |
| 阈值依据 | 4.0 = DMAX 10 的 40%（「下滑」档），与 `gq_neg_cap_0.4`(原始 composite 0.4) 同比例对齐 |
| 副作用 | Top50 至少 3 只总分下降（振华/涛涛/吉比特）；名次重排，跨口径 total 禁比（须走版本公告） |
| 验证门槛 | 需过六门槛 + walkforward；当前长面板缺 `score_size_comb` 列重建失败 ⇒ **不能验证，不进总分** |
| 保守档 | 若 4.0 过硬，可先取 5.0（与 anchor_gate 无锚档同），观察 20 日后再收紧 |

**实施顺序**：先落研究层影子分（不改 scored）→ 对照 77 只未来 20 日收益 → 若负 α 证实再申请进模型。

## 隐患二｜估值维双天花板导致优质龙头倒挂

### 根因（代码级确认）

`ep_capped` 是 `step2_stockscorer_v2.py:5360-5376` 的增速恶化封顶：
`G_q<0 或 QoQ<−20% 或 本季亏损 → score_ep≤6.0`（round105 P1-5，防低 PE 变脸票霸榜）。
`cyclic_caps` 另对周期股 `fwdPE>30 → ep≤5.0`（apply_sector:284）。
二者是**硬钉**，不区分质量：新易盛（质量 5.65、非周期、ep 封顶→6.0）排 49，
低于质量 4.8 的德明利（成长 9.82+估值 9.93）排 14，形成倒挂。

### 方案：优质龙头豁免 / 软降权（二选一，需裁决）

| 档位 | 算法 | 判据来源 | 优点 | 风险 |
|---|---|---|---|---|
| **软降权（推荐先测）** | 命中增速恶化时 `score_ep = max(6.0, ep_raw − 2.0)` 而非硬钉 6.0 | 复用 `ep_capped` 同一 `_GFB_MAP`，单一实现 | 保留区分度，避免所有恶化票估值维同分 | 需验证 −2.0 幅度不引入前视 |
| **龙头豁免** | 质量≥8 且非周期且 OCF/NI>0 时跳过 ep 硬封顶 | `score_quality`、`is_cyclic`、`quality_cash_flags` 均已落盘 | 精准修复龙头倒挂 | 质量分本身是模型产物，用它做 gate 有内生性，须防循环论证 |

| 项 | 内容 |
|---|---|
| 唯一实现 | `growth_factor_b` 或 `scale_calc` 新增 `ep_quality_gate(ep, ep_capped, quality, is_cyclic, cash_ok, mode)`，step2:5373 单点替换硬封顶 |
| 不误伤 | 保留对「本季亏损」(q_profit<0) 的硬封顶不豁免（真变脸票）；仅对「G_q<0 或 QoQ 恶化」的盈利票软降 |
| 副作用 | 9 只 `ep_capped` 中部分上修 → 估值维贡献回升，可能放大高估值敞口 |
| 验证门槛 | 须用长面板验证「豁免不引入前视偏差」，当前长面板重建失败 ⇒ **不能验证，不进总分** |
| 产品层替代 | 若不改模型，可在主页对 `ep_capped` 加徽标，让"质量 5.65 却排 49"可解释——零风险，可立即做 |

## 隐患三｜元件 8 只同链集中放大 β 敞口

### 根因与重要修正（代码级确认）

Top50 中申万二级「元件」8 只（生益/华正/金安/广合/沪电/三环/商络/深南）是**评分榜单**的富集。
但今日实际**组合**（`sector/portfolio_2026-11-27.json`）走 momentum 路线（L4 兜底），
持仓是银行/传媒/家电/食品饮料，**并不含元件**——组合层已有 `per_sector=3`/`per_parent=2`
+ v3.2 L1 暴露偏离上限（threshold 8pp，pick_portfolio:230-241/270-273），约束是生效的。

**结论**：隐患三不是"组合层缺约束"，而是"**评分榜单若被直接当组合用**"的敞口风险，
且 AI/半导体 是项目自定义的宽口径一级行业（含 PCB/覆铜板/通信设备），不等于申万一级。

### 方案：评分榜单侧的行业集中度披露 + 组合侧沿用现有约束（均不改评分）

| 项 | 内容 |
|---|---|
| 方案 3a（产品层，可立即做） | 分析页新增「Top50 申万二级集中度」区块：现算元件/通信设备/半导体等只数与占比，标注"同链 β 敞口，非行业低估证据" |
| 方案 3b（组合层，已具备） | 若老大要将评分 Top50 直接组合化，设 `per_sector=2`（现 3）+ L1 偏离阈值 8pp 不变；`pick_portfolio` 已有实现，仅调参数，无需改代码 |
| 方案 3c（模型层，谨慎） | 在 `score_size_comb` 或成长维引入行业内中性化（同行业按 rank 而非全池 rank）——属模型口径大改，须过六门槛且可能改变全部历史结论，**不建议轻易动** |
| 不误伤 | 3a/3b 不改任何分数与权重；3c 若实施须版本公告 + 跨版本 total 禁比 |
| 验证门槛 | 3a 无门槛（披露）；3b 已有组合审计；3c 须 G5 walkforward |
