② 13 个日频因子在 H=1 的 3 个可执行口径（open→close / open→open / close[t+1]→close[t+2]）下零通过（|IC|≥0.02 & |t|≥2.0 & 胜率≥55% & 扣费后>0）；同批因子在「收盘→收盘」这类不可执行对照口径下反而有通过项（rsi14 / gap）——正好证明信号躺在散户吃不到的那一段。
③ 不是"阈值没调好"——9 个生效维里没有一维是设计来预测次日方向的，fund/growth 是季度频率、quality 是年报频率，用季度因子解释日频收益是维度错配。
关键：所有日频信号都躺在「隔夜段」，而散户只能吃日内段。
把次日收益拆成 gap = open[t+1]/close[t]−1（隔夜，收盘后无法参与）与 intra = close[t+1]/open[t+1]−1（日内，开盘可买）：13 个因子里 13 个信号全在隔夜段（日内段命中 0 个），日内段无一显著（|t| 最大仅 1.77）；mom5 / dist_ma5 / dist_ma20 / vol_ratio 符号直接翻转（隔夜强负 → 日内微正）。所以「收盘→收盘」那个漂亮的 IC，散户一分钱也拿不到。
把持有期拉长能救吗？不能。H=1 通过 0 个 / H=2 通过 0 个 / H=3 通过 0 个 / H=5 通过 1 个 / H=10 通过 1 个 / H=20 通过 2 个。只有 H=20 名义跑出 2 个，但那是重叠窗口伪影：304 个日截面算 20 日收益，相邻 19 个截面重叠 95% → t 值被放大 √20≈4.5 倍（实测 2.10~6.74 倍）。按 Bonferroni 阈值 |t|≥3.22 且用不重叠截面重估后，round113 原判 4 个全部淘汰，存活 0 个。
拉长持有期唯一确定的好处是降成本频率，不是涨 IC。单周期成本 0.31%（佣金万三×2 + 印花税 0.05% + 滑点 0.10%×2），年化 ≈ 0.31%×244/H：H=1 约 76%、H=5 约 15%。
