五、权重计算与分配规则

规则 A · 现行生产规则（客观陈述，未改）

  • 目标函数 = TopN 头部超额（h=20），不是全截面 IC；依据 data/weight_p04_constrained.json（1635 日、N∈{6,10,13,30,50} 全档改善）。
  • 候选是约束内手工网格的 5 个方案（采纳 C1），不是按收益/夏普线性映射；权重改动属产品裁决，须八处同步 + verify_weights_round36 PASS 才出图。
  • 约束：Σ=1.00、单因子 ≤0.20、大类 ≤0.30、target_horizon=20；五门准入；trial 预登记。

规则 C · 「按收益／回撤／夏普线性分配」（本次实测，不采用）

映射：把各维近 1 年 Top10 超额（或超额均值÷标准差）取正值归一 → 带约束欧氏投影（SLSQP， Σ=0.80、单因子≤0.20、大类≤0.30）→ score_fund 盲区锁定 0.20 不臆造。

实测后果：7 个生效维里只有 score_growth 一个正超额，目标权重全部塌缩到该维并被 0.20 上限截断， 剩余 0.60 由约束兜底均分给零证据维（均分不是数据证据）。结果近似等权，全段净值 −22.20%， 比现行差 9.45pp。按 |IC| 排序虽净值 −8.69% 略好，但方向与目标函数相反、属明令禁用，且样本内挑出来的结果不可采信。

规则 B · 建议采用：证据充分度收缩（本次给出的判断方法）

w = (1−λ)·w_prior + λ·w_data，其中 λ = clip((t_max−2)/(thr−2), 0, 1) × clip(n_eff/30, 0, 1)。
代入实测：t_max=1.1608、thr=3.8135、n_eff=10.75 ⇒ λ = 0 ⇒ 最终权重 = w_prior（现行 v4.19）。
含义：权重不是「按表现排序重分配」，而是先验 + 经多重检验与样本量校正后的有限偏移； 证据不足时偏移必须归零。这既避免单年过拟合，也与「禁按 IC 排权重」「G5 未过不重测」一致。

完整触发顺序：补数据 → 固定权重只跑验证（不改权重）→ 仅当验证证伪现行权重 → 才在约束内重解 → 五门 + 八处同步 + 页面披露同步。
