## 2. 问题诊断：不是方向，是分辨率

### 2.1 绝对值口径把分数压塌了

改前全池 1921 只的分布：

| 维度 | 均值 | 中位 | **满分 5.0 只数** |
|---|---|---|---|
| `score_rsi_rev` | 3.45 | 4.00 | **384** |
| `score_bias60` | 3.53 | 4.00 | **858（44.7%）** |

`bias60` 有 44.7% 的股票拿满分 → 这一维对近半数池子是**常数**，等于实际只在对另一半排序。

### 2.2 连续口径优于分档口径（本轮决定性发现）

| 口径 | h20 IC | 说明 |
|---|---|---|
| `bias_raw`（原始连续值） | **+0.0461** | 全表最高 |
| `bias_only`（分档） | +0.0360 | 现行做法 |
| `rsi_raw`（原始连续值） | +0.0341 | — |
| 两维合并 IC | +0.0348 | **不优于任一单维** |

合并后并不优于单维，说明**两维高度共线**：`Spearman(score_rsi_rev, score_bias60) = +0.7625`（原始口径 +0.8597）。

**结论**：绝对阈值丢失了连续信息，这比「加确认门」更本质。但两维共线过强，直接合并成单一维度会丢失信息 → **保留两维，改为池内分位以提高各自分辨率**。

## 4. 落地改动（3 处 + 1 处纠偏）

### 4.1 `step2_stockscorer_v2.py` 改动 1：新增两个纯函数

```python
def reversal_rank(raw_vals, higher_is_better):
    """一批原始反转指标 → 池内 rank 分位分（0-5）。
    ⚠️ 与 score_lowvol20_rank 同口径（rank→pct→×量程），但量程是 5 不是 10，
       因为 score_bias60/score_rsi_rev 的 DIM_MAX = 5.0。写错成 0-10 会让两维实际权重翻倍。"""

def reversal_confirm_gate(kl, n_low=20):
    """止跌确认门。确认 = 至少满足其一：①未创20日收盘新低 ②收盘站上MA5 ③当日收阳
    ⚠️ 刻意不含「站上MA20」：全样本 495,587 观测中「站上MA20」的最小 RSI = 35.45，
       RSI<30 的 20,449 个样本命中 0 个 → 结构性空集。
    ⚠️ 也不含「企稳信号≥2个」：实测企稳信号个数与未来收益**反向**。"""
```

原 `score_rsi_rev()` **保留不动**，降级为「池内分位不可算时的绝对阈值兜底」。

### 4.2 改动 2：构建池内分位表（`lowvol20` 之后）

```python
_rev_raw_rsi, _rev_raw_bias, _rev_gate = {}, {}, {}
for _s in stocks:
    _kl = klines.get(_c) or []
    if len(_kl) < 61: continue
    _cls = [k["close"] for k in _kl]
    _r = rsi(_cls, 14)
    if _r is not None: _rev_raw_rsi[_c] = _r
    _m60 = sum(_cls[-60:]) / 60.0
    if _m60 > 0: _rev_raw_bias[_c] = (_cls[-1] - _m60) / _m60 * 100.0
    _g = reversal_confirm_gate(_kl)
    if _g is not None: _rev_gate[_c] = _g
_rsi_rank5  = reversal_rank(_rev_raw_rsi,  higher_is_better=False)
_bias_rank5 = reversal_rank(_rev_raw_bias, higher_is_better=False)
```

实跑日志：`🔁 反转两维池内分位表: RSI 1920/1921 只（池内中位 39.0），BIAS60 1920/1921 只（池内中位 −13.2%）｜止跌确认门: 1336/1920 只已确认`

### 4.3 改动 3：唯一调用点改为「优先分位 / 兜底阈值 / 深跌未确认罚分」

```python
_rev_conf = _rev_gate.get(code)
```

## 9. 对外可用的表述边界

**可以说**：
- 反转两维从绝对阈值改为池内分位后，h20 IC 由 +0.0348 升至 +0.0410（C3）/ +0.0450（C6），`t_NW` 由 0.62 升至 0.71~0.78
- 四个季度中三个优于原口径，2026Q1 由负转正
- 满分塌缩（858 只 → 0 只）已消除，该维恢复区分度

**不可以说**：
- ❌ 「反转因子已被验证有效」—— `t_NW = 0.71~0.78`，远未达到 `(n,lag)` 对应的真实临界值（本样本 `n≈229 / lag=19` 时零分布 95% 分位远超 3.81）
- ❌ 「过了 Bonferroni」—— 唯一过线的是 `score_attention` 且方向为负
- ❌ 「改后收益提升」—— 本轮只测 IC 与排序质量，**未做组合层回测**；`Q5−Q1` 由 +1.038pp 降到 +0.748pp（C6），**分位数价差实际上是下降的**
- ❌ 2026Q2 该维为负（−0.0958），**下跌市中会失效**

**必须同时披露**：
- 2026Q2 为负（−0.0958 / t=−2.48）
- `Q5−Q1` 从 +1.038pp 降至 +0.748pp，与 IC 提升方向相反 —— 说明改进在**整体排序**而非**两端极端**
- 罚分只覆盖 RSI<30，且 `t_sub` 仅 1.55（不重叠子样本 8 天）
