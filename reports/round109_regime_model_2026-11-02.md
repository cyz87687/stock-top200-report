## 二、为什么不引入 Transformer（结论在 2873 日样本上更硬）

### 2.1 方向预测：12/12 组全部输给「永远猜震荡」

`audit_round109_regime_feasibility.py`，walk-forward（含 **purge gap = H 日**，
防 t 日标签覆盖 t→t+H 造成跨折重叠 —— round72 前视教训同源）。

**标签**（三分类，滚动自适应阈值）：
```
r_H = close[t+H]/close[t] − 1
θ_t = 0.75 × σ20_t × sqrt(H)        # σ20_t 只用 ≤t
r_H ≥ +θ_t → 涨(1)；≤ −θ_t → 跌(2)；其余 → 震荡(0)
```

**2873 日样本实测（逻辑回归 vs 多数类基线）**：

| 指数 | H | acc | 基线 | 差距 |
|---|---|---|---|---|
| 沪深300 | 10 | 0.450 | 0.611 | **−16.1pp** |
| 中证全指 | 20 | 0.394 | 0.571 | **−17.7pp** |
| 中证全指 | 10 | 0.439 | 0.500 | −6.1pp |
| … | | | | **12/12 全负** |

> v1 是 8/12 负、差距最大 −17.7pp；v2 扩样本后 **12/12 全负**，但差距收窄到 −3.8pp 以内。
> 含义：**方向信号不存在这件事，样本越长越确定**；不是「样本不够所以测不出」。

### 2.2 深回撤预测（T2）：v1 的核心结论被自己推翻

这是本轮**最需要交代**的一件事。v1 曾基于 T2 设计「三档降仓」，理由是：

> 440 日：T2 AUC 0.727~0.786（9/12 过 0.63）、经济价值 3/8 通过、Sharpe 改善 7/8

扩到 2873 日后：

| 指标 | 440 日 | 2873 日 |
|---|---|---|
| T2 AUC | 0.727~0.786 | **0.509~0.587**（≈随机 0.5） |
| 经济价值通过 | 3/8 | **0/8** |
| MDD 改善 | 多数为正 | **多为负**（中证500 H=10：−13.1%） |

**结论：v1 的 T2 是小样本运气。若继续用它调仓位，就是拿噪声当信号。**
故 v2 已移除 T2，`risk_temperature()` 只保留「当前刻度」语义，不再声称预测未来。

### 2.3 T1 波动率预测反而更稳 → 只保留这个

| 方法 | AUC（2873 日） | 稳定性 |
|---|---|---|
| 零训练 vol 分位 | **0.675~0.770**（8/8 组 >0.63） | 稳定 |
| 拟合模型（LogitBin） | 0.586~0.682 | 逐折剧烈摆动（沪深300 H=10 曾出现 `[0.345, 0.192, …, 1.0, 0.0, …]`，倒挂折 34/66） |

**零训练分位优于拟合模型** —— 在波动中枢漂移的环境里，分位法天然免疫分布漂移。
这是被数据逼出来的选择，不是偏好。

## 三、输入特征（全部 ≤t，无一例外）

| 特征 | 定义 | 用途 |
|---|---|---|
| `close` | 收盘价（`[open, close, high, low]`，row[1]） | 全部计算基础 |
| `ret20` | 20 日收益 | 趋势强度辅助 |
| `vol20` | 20 日对数收益标准差 × √252 | L1 高波动判定 + L2 刻度 + 风险预算 |
| `vol_pct` | `vol20` 在近 250 日的分位（≥120 日才出） | L2 刻度 |
| `ma20` / `ma20_slope` | MA20 及 10 日日均斜率 | L1 趋势判定 |
| `dd60` | `close / max(close[-60:]) − 1` | L2 刻度 |
| `dd_pct` | `−dd60` 的近 250 日分位 | L2 刻度 |

**不用**：北向资金（已停发）、两融（口径变更）、估值（与本模块无关）、
涨停家数等横截面宽度（**仅 2025-07 起可得，无法回测**）。

## 五、决定性负面结果：降仓择时为什么无效

### 5.1 数据

| 指数 | 满仓 MDD | vol≥90% 降仓 0.3 后 MDD | 触发天数 |
|---|---|---|---|
| 中证全指 | −41.58% | **−53.47%（更深）** | 12% |
| 沪深300 | −45.60% | **−53.22%（更深）** | 12% |
| 中证500 | −49.28% | **−61.44%（更深）** | 14% |
| 中证1000 | −61.61% | **−74.25%（更深）** | 13% |

**降仓后最大回撤反而更深** —— 这违反直觉，我逐段核实了路径。

### 5.2 根因：A 股高波动期恰恰是大幅反弹期

`vol_pct ≥ 0.90` 的触发段里，满仓收益：

| 触发段 | 天数 | 该段满仓收益 |
|---|---|---|
| 2024-09-26 ~ 2024-11-05 | 24 | **+20.76%** |
| 2018-10-11 ~ 2018-11-12 | 23 | **+5.32%** |
| 2018-02-06 ~ 2018-03-15 | 23 | **+3.15%** |
| 2024-01-17 ~ 2024-03-12 | 34 | **+5.60%** |

2015 救市、2018-10 政策底、2024-09-24 反攻 —— **全部发生在波动率分位最高的时候**。
在这些时点降仓 = 系统性错过反弹。

**复利路径后果**（中证全指）：
- 净值峰值日：满仓 2026-05-12 → 降仓方案退回 **2015-12-21**（11 年未创新高）
- 年度：2018 满仓 −31.5% → 降仓 **−36.4%**；2022 −19.2% → **−24.5%**；2024 **+5.3% → −10.8%**

### 5.3 这个结论的价值

它把「要不要做择时降仓」这个问题**永久关死**了，不是「参数没调好」。
若未来有人再提「波动率高就减仓」，这里有 2873 日、4 指数、5 规则的反证。

## 六、v2 设计：不预测，只换算

### 6.1 三层结构（语义已收紧）

| 层 | 内容 | 语义 | 置信度 |
|---|---|---|---|
| L1 状态识别 | 趋势涨 / 趋势跌 / 高波动 / 震荡 | **描述现在** | high（零训练） |
| L2 风险刻度 | 波动分位 + 回撤分位 → 0~1 | **当下读数，非预测** | medium |
| 风险预算 | `0.15 ÷ realized_vol` → 仓位上限 | **恒等式** | high（算术） |
| L3 方向预判 | 不提供 | — | none |

L2 的阈值：`temp = max(vol_pct, 0.5·vol_pct + 0.5·dd_pct)`；
`≥0.75 高 / ≥0.50 中 / 其余低`。取 max 的理由：高波动本身就是风险，不该被低回撤稀释。

### 6.2 风险预算（这是「风险预算上限调整逻辑」的答案）

```
仓位上限 = 目标波动 / 当前已实现波动      # 目标 15%（年化），clip 到 [0.30, 1.00]
```

**必须披露的代价**（写进代码注释、页面、本文件三处）：
该换算会**降低长期收益**（A股波动与收益正相关），换来的是风险暴露稳定。
它是**风险偏好选择，不是收益增强手段**，更不是 alpha 来源。

### 6.3 今日实测（2026-11-02）

```
日期门禁：指数最新 2026-11-02 = 数据日期 2026-11-02 ✅（滞后 0 天）
L1：单边下跌市（收盘低于 MA20 5.21%、MA20 斜率 −0.58%）
     ⚠️ 一致性标注：当日 +1.66% 属「下跌趋势中的反弹」，趋势未反转
L2：风险刻度 0.844（高）｜波动分位 69.2%｜回撤分位 99.6%（距60日高点 −17.8%）
风险预算：15% ÷ 22.11% = 0.68 → 上限 68%
敞口衔接：情绪阶梯 80%~100% vs 风险预算 68% → 取小 68%（受风险预算约束）
背离标注：情绪顶（赚钱效应高 + 风险刻度高）→ 不加仓
四指数：中证全指/沪深300 = 单边下跌市；中证500/中证1000 = 高波动市 → 置信度降为 medium
```

## 七、与赚钱效应 82 分的衔接（改为取小，不是相乘）

### 7.1 先看 82 分是什么

`step2_stockscorer_v2.py: compute_money_effect()`：
```
c_breadth = clamp((up占比 − 0.30)/0.40 × 40, 0, 40)     # 广度，40 封顶
c_zt      = clamp((涨停−跌停) × 0.35, −12, 18)          # 涨停净额，18 封顶
c_idx     = clamp(三指数均值 × 6.0, −15, 25)            # 指数强度
c_med     = clamp(中位涨幅 × 6.0, −10, 15)              # 中位涨幅，15 封顶
score = clamp(round(sum), 0, 100)
```
今日 82 分 ≈ 广度 40（封顶）+ 涨停净额 18（封顶）+ 指数 ≈9 + 中位涨幅 15（封顶）。
**它是情绪满分档，且 100% 来自当日截面，不含任何前瞻信息。**

### 7.2 为什么改相乘为取小

v1 是 `82 × 高风险 → ×0.70`，再乘在原阶梯上（80%~100% × 0.70 = 56%~70%）。

**问题**：赚钱效应 82 分**本身已经**通过阶梯给出了「8成+警惕」的谨慎；
风险刻度又给一个 0.70 —— 两者相乘等于**同一份谨慎计了两次**。
若风险预算也是 0.70，就变成 0.70×0.70=0.49，过度保守且无法向人解释。

**v2 改为**：
```
实际敞口上限 = min( 情绪阶梯上限, 风险预算上限 )
```

| 约束 | 今日值 | 来源 |
|---|---|---|
| 情绪阶梯上限 | 80%（8成+警惕 = 80%~100%） | `POSITION_LADDER` 原值，**未改写** |
| 风险预算上限 | 68% | `0.15 ÷ 0.2211` |
| **取小 → 执行** | **68%** | 受风险预算约束 |

语义干净：**谁更保守听谁的**。三个数都可单独追溯与推翻，不会被乘法揉成一个不可解释的数字。

### 7.3 背离矩阵（信息量所在，但不参与计算）

| 组合 | 含义 | 标注 |
|---|---|---|
| 高情绪(≥80) × 高风险 | 情绪顶 | 不加仓（今日属于此类） |
| 低情绪(<40) × 低风险 | 磨底 | 不必降到最低档 |
| 其他 | 同向 | — |

## 九、日期硬门禁（老大明确要求「2、需要加」）

### 9.1 设计

```python
check_date_gate(bench, data_date, max_lag_days=0)
```

- `data_date` 从**最新 scored 文件**的 `date` 字段读取（单一数据源，不另建口径）
- 指数最新交易日 vs 数据日期不一致 → `ok=False`
- 三种 action：`pass` / `stale_bench` / `no_data_date`（后者明确标注「门禁未执行 ≠ 通过」）

### 9.2 行为（三条路径全部实测）

| 场景 | 行为 | 实测 |
|---|---|---|
| 日期一致 | 正常生成 | ✅ `11-02 = 11-02`，exit 0 |
| 指数落后 | **拒绝生成、不落盘、exit 2** | ✅ 伪造 `--data-date 2026-11-05`，exit 2，无输出文件 |
| 确需放行 | `--allow-stale` → 生成但标记，页面显示告警 | ✅ 已测 |

### 9.3 三层防御

1. **生成层**：`regime_model.py` 门禁拦截 → 不产出 `regime_forecast.json`
2. **展示层**：报告读取时若日期不符 → 卡片显示「数据管道告警」占位（**不是静默跳过**）
3. **日链层**：`run_daily_local.sh` 区分 exit 2 与普通失败，写入显式日志

> 为什么展示层不能静默跳过：静默跳过会让读者以为「今天没有风险信息」，
> 而真相是「数据管道坏了」—— 两者需要完全不同的处置。

5. 全部结论只基于**一个市场（A股）**，不能外推。
