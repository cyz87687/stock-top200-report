## 0. 老大裁决方向（本轮红线）

> 「不应该去掉技术面因子，优化反转簇因子，反转应该需要跟确定性信号配合，比如量价和多头排列」

三条硬约束：
1. **反转簇权重一分不动**（维持 v4.16.1：tech_neg .10 / rsi_rev .10 / bias60 .05 = .25）；
2. **改造因子本身**：反转高分必须由确定性信号确认，无确认的超跌不得分；
3. 确认信号 = **量价配合** + **多头排列**（老大点名）。

## 1. 现状诊断：反转簇是「无条件反转」

三因子现行口径（`step2_stockscorer_v2.py`）：

| 因子 | 逻辑 | 满分条件 | 确认要求 |
|---|---|---|---|
| score_rsi_rev | RSI14 越低分越高 | RSI<30 → 5.0 | **无** |
| score_bias60 | 乖离 (P−MA60)/MA60 越负越高 | ≤−15% → 5.0 | **无** |
| score_tech_neg | 10 − score_tech（技术面反号） | 技术面越差越高 | **无** |

**实锤（2026-10-30 池）**：现行前十**全部**是「双线空头 + 近5日大跌 + 缩量」的单边下跌票——

| 现行# | 名称 | total | trend | mom5 | amt_ratio | 反转簇得分 |
|---|---|---|---|---|---|---|
| 1 | 圣晖集成 | 82.55 | 双线空头 | −10.5% | 0.81 | tech 8.4 + rsi 4.0 + bias 5.0 |

## 2. 改造设计：触发 × 确认 两层结构

```
反转得分 = 触发层 T（沿用现行反转分，口径不动）
            × 耦合函数（三选一）
            （确认层 C = 0.5·V 量价 + 0.5·M 均线）
```

### 2.1 确认层定义（全部取自 tech 字段，已有数据，无新增数据源）

**V 量价确认（0~1）** — amt_ratio(5日额/20日额) × mom5(5日涨幅) 联合：

| 量价状态 | V |
|---|---|
| 放量反弹（mom5≥3% 且 amt≥1.2） | 1.0 |
| 温和放量回升 / 价稳量增（\|mom5\|≤3% 且 amt≥1.0） | 0.8 |
| 缩量企稳（\|mom5\|≤3% 且 amt<0.85，抛压衰竭） | 0.6 |
| 温和回升（0<mom5<3%） | 0.65 |
| 缩量阴跌（mom5<−3% 且 amt<1.0） | 0.1 |
| **放量下跌（mom5<−3% 且 amt≥1.2，出货）** | **0** |
| 缺失 | 0.35（中性偏低，禁臆造满分） |

**M 均线确认（0~1）** — 多头排列等级（老大点名）+ MA60 位置：

| 均线状态 | M |
|---|---|
| 双线多头（日线+周线 MA5>MA10>MA20） | 1.0 |
| 周线多头 | 0.85 |
| 金叉（MA5 上穿 MA20） | 0.75 |
| 日线多头 | 0.7 |
| 偏多（MA5>MA20） | 0.5 |
| 缠绕 | 0.3 |
| 偏空/死叉 | 0.15 |
| **空头排列（日/周/双线空头）** | **0** |
| 加项：价格站上 MA60 | +0.1 |

**C = 0.5·V + 0.5·M**。当前池分布：median **0.12**，C≥0.55 仅 300/2042（10 月末普跌，弱确认是常态——这正是因子要识别的）。

### 2.2 耦合方式（三选一）

| 代号 | 公式 | 语义 |
|---|---|---|
| **G1 乘法门控** | T×(0.4+0.6·C) | 无确认最多拿 40% 触发分，满分必须双确认 |
| **G2 封顶门槛** | C<0.35 封 T/2 ；C<0.55 封 0.8T ；≥0.55 不动 | 无确认打折封顶，有确认全额 |
| **G3 加法重构** | 0.6·T + 0.4·满量程·C | ⚠️ 已淘汰：没触发只靠确认也能登顶（亚宝药业 C=1.0 靠确认分登顶 G3 榜首），违背「反转×确认」本意 |

### 2.3 门控范围（RA vs RB）

| 代号 | 范围 | 理由 |
|---|---|---|
| **RA** | tech_neg + rsi_rev + bias60 全门控 | 贴老大语义：反转类高分一律要确认 |
| **RB** | 只门控 rsi_rev + bias60，tech_neg 保留 | tech_neg = 10−score_tech 是反转块内部对冲（v4.4 设计），保留对冲结构 |

## 5. 风险披露（如实）

1. **75 门槛口径**：G1 乘法把全池天花板压到 72.84，≥75 卡片清零（`_TOTAL_MIN=75` 产品门槛是按现行口径标定的）。若走 G1 需同步重标门槛或改分位制——这是产品裁决不是技术问题。G2/RB 无此问题。
2. **确认系数无 IC 证据**：V/M/C 的档位阈值（amt≥1.2、mom5≥3% 等）是设计值+技术面常识，**未经回测门禁**。落地后须补：panel_round67 增列 C 值 → weight_admission_gate 验证反转簇门控版 IC/ICIR；盲区解除前维持灰度表述。
3. **tech_neg 双重门控争议（RB vs RA）**：tech_neg 本身=10−score_tech，score_tech 内含均线/量能子因子——给 tech_neg 再套 C 是「用均线确认一个反均线的分」，语义自洽（反转必须被趋势确认）但有双重计量味道。RB 只门控纯反转二维可回避，代价是 tech_neg 8.2 的无确认高分仍保留。**这是 D2 裁决点。**
4. **单边下跌市的地板效应**：当前池 median C=0.12，门控后反转簇整体贡献≈腰斩，因子多样性下降——但这恰是「不接飞刀」的本意；等右侧信号出现（金叉+放量）分数自然回来。
5. 未过 G5 walk-forward、P0 池前视未闭合、ES 覆盖缺口 76/2042——三条旧缺口原样存续，禁宣称「经验证的 alpha」。
