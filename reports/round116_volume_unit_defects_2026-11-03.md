### 2.3 为什么判据必须用东财，不能库内自证

三代判据的实测对比（这是本轮最重要的方法论教训）：

| 版本 | 判据 | 结果 | 问题 |
|---|---|---|---|
| v1 | 用「**前一日** vol」作基准，`r ∈ [50,200]` | 修 1,771 只，拒绝 0 | **漏 35 个组合**；688658（全历史是股，r=0.73）和 603131（当日真实暴量 r=848.88）都漏 |
| v2 | 用「该股**其余日期中位数**」作基准，`r ∈ [50,300]` | 修 **1,109** 只，另 441 只被误挡 | **漏 716 只** |
| **v3** | **东财逐只核对**（`verify_vol_unit_em.py`） | 修 **1,825** 只，异常 0 | ✅ 无歧义 |

**v2 为什么失败**：`该日vol / 历史中位vol` 的分布（实测 n=1,818）是**单峰对数正态**，
中位 ≈100，但区间横跨 **20 ~ 2000**（当日真实量对历史中位量本身就有 2 个数量级自然波动）：

```
r≈    50.12  n=85        r≈   199.53  n=168
r≈    63.10  n=184       r≈   251.19  n=103
r≈    79.43  n=229       r≈   316.23  n=74
r≈   100.00  n=290       r≈   501.19  n=34
r≈   125.89  n=277       r≈  1000.00  n=7
r≈   158.49  n=219       r≈  1995.26  n=1
```

→ 任何固定比值区间都只能随机命中约 60%。**"库内自证"这条路根本走不通，必须引入外部权威源。**

## 三、缺陷 B：audit 脚本成交额漏乘 100（跨全历史）

### 3.1 缺陷定位

11 个脚本统一写法：

```python
A[i, j] = v_ * c_          # ❌ 非 688 的 v_ 单位是「手」，漏乘 100
```

受影响脚本（全部已改为 `v_ * vol_coef(cd) * c_`）：
`audit_round111_t0_t1_factors` / `111b` / `111c` / `113_holding_period` / `113b_holdout` /
`114_t0_cost_ceiling` / `114b` / `114c` / `114d` / `114e` / `114f`

**修复方式**：新建单一来源 `kline_units.py`

```python
def vol_coef(code):
    return 1.0 if str(code).startswith("688") else 100.0

def bar_amount(code, vol, close):
    return float(vol) * vol_coef(code) * float(close)
```

项目纪律「同一口径两处实现必然漂移」→ 11 处实现收敛为 1 个函数。

## 四、方法论沉淀（可复用，必须写进 MEMORY）

### 4.1 教训 ①：库内自证 ≠ 权威口径

用「该股历史中位数」作基准判断单日异常，看似稳健，实则**基准本身也有 2 个数量级的自然波动**。
任何纯库内的比值判据，命中率上限受限于「自然波动幅度」。
**→ 数据单位/口径类问题，必须引外部权威源做一对一比对，不能自证。**

### 4.2 教训 ②：报"修复了 N 只"之前必须做减法校验

v2 报「修复 1,109 只、跳过 441 只」看起来像个正常结果，
但真实待修 1,825 只 → **漏了 716 只（39%）**。
判据：**总数 − 修复数 − 设计内跳过数 应 ≈ 0**。
1,825（真值）vs 1,109（修复）→ 差额 716 无合理解释 → 应当立即质疑。
**→ 修复类脚本必须输出「应修 / 已修 / 设计内不动 / 无法归类」四分表，且"无法归类"必须为 0。**

### 4.3 教训 ③：同一单位错误会在"下游"再犯一次

缺陷 A（单日）修好后，缺陷 B（跨全历史漏乘 100）才暴露出来——
而且 B 的**方向相反**：A 是把「手」误写成「股」（夸大 100 倍），
B 是把「手」当「股」用（缩小 100 倍）。
**→ 修完一个单位 bug，必须扫一遍所有消费该字段的地方，检查是否反向错。**

### 4.4 教训 ④：「唯一可信候选」在样本放大 21 倍后经济价值腰斩

n=188 → 4056，均值 −56%、胜率 −7.6pp。
这正是方法论⑫（小样本"通过"必须扩样本复核）的**第二次实证**。
**→ 任何 <300 样本的结论，一律标注「样本量不足，禁止作为生产依据」。**
