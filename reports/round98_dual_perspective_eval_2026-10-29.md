# A股 TOP200 评分系统 — 双视角方案评估与优先级修改清单

> 评估日期：2026-10-29
> 评估对象：线上 v4.15-constraint-cap + 第九轮（round92~97）8 因子验证流程与 v4.16 候选
> 评估立场：专业量化研究员（研究严谨性）× 专业投资者（实盘可行性）
> 数据来源：`factor_weights.json`、`audit_round92~97.json`、`data/panel_round66.json`、`data/val_arrays_h20.npz`、`top200_scored_*.json` 全部实读复算，无推断数字
> 铁律：线上权重未改动（version 仍为 `v4.15-constraint-cap`，Σw=1.000000），HEAD 保持 `4d76e26`

---

## 〇、核心结论（先看这一段）

本轮评估**推翻了三项此前被认为成立的前提**，均基于实读数据复算：

| # | 此前假设 | 实测事实 | 影响 |
|---|---|---|---|
| **C1** | round97 得出 `fund 权重=0`，说明 fund 无效 | **求解面板本身缺 fund 数据**：`panel_round66.json` 中 `score_fund` 仅 **80/238** 个截面有值，中位覆盖率 **0.0000**，最高仅 **0.2252**；`val_arrays_h20.npz` 的 dim0（=fund）每期中位有效数 **0 只**。而生产 scored 文件 fund 实际覆盖率 **89.58%（2415/2696）** | round97 中 fund=0 是**数据缺失导致的伪结论**，不可作为降权依据 |
| **C2** | v4.16 候选（minimax 解）优于基线，ICIR 0.5608 | 内部验证段（19 截面）minimax 解 ICIR = **−0.2592**（t=−0.80），**劣于** v4.15 基线 −0.0812；而最简单的 9 因子等权 ICIR = **+1.1419（t=2.66）** | minimax 解是**求解段过拟合**，19 个截面的独立验证即翻负 |
| **C3** | 组合整体具备正 alpha | round96 中 **全部 5 个方案的 Q5−Q1 分层 spread 均未通过**：基线 −0.0003、minimax −0.0167、9 因子等权 +0.0098、size_growth 单维 −0.0028、5 因子等权 −0.0174。且 B/D/E 三方案 spread 为**负** | 分层单调性未建立，**"打分越高收益越高"在检验区间内不成立**，这是比 ICIR 更根本的失效 |

**因此，当前方案距离"可作为实盘依据"存在一个前置性缺口：验证所用的数据面板与生产环境不一致（C1），导致第九轮全部权重结论需要重新判定。**

## 一、优先级修改清单（按价值提升降序）

### P0-1｜修复验证面板与生产口径的断裂（fund 维缺失）

| 项 | 内容 |
|---|---|
| **现存问题** | 权重求解/盲测使用的 `data/val_arrays_h20.npz` 与 `data/panel_round66.json` 中，`score_fund` 覆盖率中位数 **0.0000**、仅 80/238 截面有值，最高 22.52%。而生产 `top200_scored_2026-10-28.json` 中 fund 覆盖率 **89.58%**。两者相差 **约 3.5 倍覆盖缺口**。 |
| **为何是最高优先级** | 因子验证的第一性前提是"验证面板 = 生产实际输入"。fund 在线上权重中占 **0.200**（第二大权重），却在验证面板里近乎全缺。这直接导致：① round97 把 fund 压到 0（伪结论 C1）；② 所有基于该面板的 IC/ICIR/分层结论对 fund 全部失真；③ 若据此上线 v4.16，等于在**未验证过的维度上做了一次 20% 权重的隐性削减**。 |
| **修改方案** | ① 追查 `panel_round66.json` 的 fund 列生成路径（当前 `panel_round34.json` 为源，`meta.purpose` 称"quality 用修复后代码逐截面重算"，但 fund 未同步重建）；② 以生产 `score_fund` 的同源算法，对 238 个截面逐截面重算 fund；③ 重建 `val_arrays_h20.npz`；④ 重跑 round92~97 全链；⑤ 输出"修复前后"权重结论对比表。 |
| **依据** | 实读数据：`panel_round66.json` fund `dates_with_data=80/238`、`median_cov=0.0000`、`max_cov=0.2252`；`val_arrays_h20.npz` dim0 `median_valid=0`、`max=189`；生产 scored `fund non-null 2415/2696=0.8958`。 |
| **预期价值增益** | **极高**。这是唯一能让第九轮结论从"不可用"变为"可用"的动作。修复后 fund 的真实有效性才第一次得到检验，且**可能同时改变 quality/ep/lowvol20/size_growth 的权重结论**（因组合 IC 是联合估计）。 |
| **实施难易度** | **中高**。需定位 fund 生成链路并逐截面重算，但基础设施（`factor_validation_core.py`、逐截面 PIT 修复代码）已具备，主要是工作量与验证。 |
| **潜在风险** | 若 fund 的历史数据本身不可回溯（如依赖当时不可得的财报 PIT），重算可能引入前视。**必须先确认 fund 的 PIT 可得性，不可用未来财报填充**。 |

### P0-2｜把"样本外盲测"从 19/110 截面提升到有统计功效的规模

| 项 | 内容 |
|---|---|
| **现存问题** | round97 求解段 90（涨市）+71（跌市），内部验证段仅 **19 个截面**，样本外盲测 110 截面但月度调仓仅约 **7 期**。round96 明确标注"月度调仓约 7 期，功效极低"。 |
| **为何是最高优先级** | 三条量化铁律：① 19 截面 ICIR 的标准误约 0.23（sd≈1.0/√19），点估计 −0.259 与 +1.142 的差（1.40）虽显眼但**单点验证不足以定论**；② 7 期组合净值的年化系数为 **252/140=1.80 倍**，即年化数字被放大近一倍，B 方案"年化 58.01%"对应的**期间累计仅 +28.94%**，D 方案"年化 191.94%"对应**累计 +81.34%**——这类数字在 7 期样本上不具备外推性；③ 一个需要 210 个候选网格中挑最优、且验证段仅 19 点的流程，**过拟合概率极高**（C2 已实证翻负）。 |
| **修改方案** | ① 把日频截面（219 个）作为**主口径**，月度仅作对齐参考，并在所有输出中强制并列"n 截面 / n 期"；② 把求解段/验证段改为**滚动前推（walk-forward）**而非单次切分：每次用前 k 个截面求解、紧接其后 m 个截面验证，滚动至少 8~10 折；③ 组合净值报告一律以**期间累计收益**为主、年化为辅，且年化必须标注"基于 n 期、放大系数 1.80x，仅供同口径比较"。 |
| **依据** | `audit_round97.json` `segments.inner_val` 长度=19、`out_blind` 长度=110；`audit_round96.json` `locked` 注明月度调仓约 7 期、"功效极低"；`n_periods=7` 全部方案一致；140/252 交易日换算。 |
| **预期价值增益** | **极高**。把"能不能用"的判断从单点赌博变为分布判断。walk-forward 是量化研究可信度的最低门槛，缺此则任何权重结论都无法证伪。 |
| **实施难易度** | **中**。`factor_validation_core.py` 已有 `combo_ics_at()`（支持非连续截面逐截面取样），只需外层加滚动折循环，无需重写核心。 |
| **潜在风险** | 滚动折增加后，各折结论可能高度离散——**这本身就是有价值的发现**（说明 regime 依赖强），不应被视为"结果不稳定"而回退到单次切分。 |

### P0-3｜正视"分层单调性未通过"这一根本失效

| 项 | 内容 |
|---|---|
| **现存问题** | round96 五个方案的 COMBO 五档均值全部不单调，且三个方案 Q5−Q1 为负：<br>· v4.15 基线：`0.0251 / 0.0339 / 0.0333 / 0.0344 / 0.0248`，spread **−0.0003**<br>· minimax：`0.0362 / 0.0374 / 0.0261 / 0.0324 / 0.0195`，spread **−0.0167**<br>· 9 因子等权：`0.0222 / 0.0328 / 0.0308 / 0.0336 / 0.0320`，spread **+0.0098**<br>· 仅 size_growth：`0.0428 / 0.0355 / 0.0187 / 0.0157 / 0.0400`，spread **−0.0028**<br>· 5 因子等权：`0.0359 / 0.0338 / 0.0325 / 0.0307 / 0.0186`，spread **−0.0174** |
| **为何是最高优先级** | 分层单调性是选股模型的**业务可解释底线**。投资者使用 TOP200 榜单时，默认"排名越靠前越好"。若 Q1 与 Q5 收益无差甚至反向，模型输出的排序**不可用于任何仓位决策**，无论 ICIR 多高。这不是统计细节，是产品可用性问题。 |
| **修改方案** | ① 把"分层单调性"从验收项之一升级为**一票否决项**：spread ≤ 0 的组合直接不进入候选，不做"其他指标好就放行"的妥协；② 诊断 spread 为负的结构性原因——从数据看，**Q1（最低分档）普遍收益偏高**（基线 0.0251 < Q4 0.0344 但 > Q5 0.0248），提示低分档中混入了"高收益但被技术面/低波惩罚"的标的，需检查**惩罚性维度是否过度**；③ 若确认是惩罚维度造成，考虑改为**双榜**（进攻榜按纯 alpha 排、防守榜按风险调整后排），而非强行压成一个总分。 |
| **依据** | `audit_round96.json` `verdicts.*.combo_layer.means/spread`，`pass=false` 全 5 个方案。 |
| **预期价值增益** | **极高**。直接决定榜单能否被用于选股。修复后即使 ICIR 不提升，产品的**可用性**也会有质变。 |
| **实施难易度** | **中**。"一票否决"是纯流程改动（易）；诊断惩罚维度过度需重跑分层并做维度剥离实验（中）。 |
| **潜在风险** | 严格一票否决后**可能没有任何方案通过**（当前 5 个全不通过）。必须提前接受"当前模型不具备可上线条件"这一结论，而非放宽标准让它通过。 |

### P1-1｜消除"惩罚性维度挤占打分"的结构性冲突

| 项 | 内容 |
|---|---|
| **现存问题** | round94 显示 4 个维度的 IC 在涨/跌市**符号完全翻转**：`ep`（+0.031→−0.062 反向，跌市 t=4.87）、`lowvol20`（+0.034→−0.087，跌市 t=3.89）、`rsi_rev`、`tech_neg` 同型。这四个维度合计名义权重（线上 v4.15）：ep **0.120** + lowvol20 **0.200** + rsi_rev **0.0756** + tech_neg **0.0288** = **0.4244**，即 **42.44% 的权重建立在符号随市场状态翻转的因子上**。 |
| **为何重要** | 这是 C3（分层失效）的**机制解释**：当 42% 权重来自符号不稳定的维度时，总分排序在不同市场状态下会系统性错配，导致 Q5 组合在涨市被低波/反转因子拖累。同时这也解释了记忆中的"模型是防御型选股器"——防御因子在跌市有效、涨市反向。 |
| **修改方案** | ① 承认符号翻转是**结构性事实**（round94 已实证，t 值 3.4~4.9 显著），不再试图用单一权重兼容两种 regime；② 落地为**两套权重 + 事前 regime 判定**：涨市权重（重 size_growth/quality）、跌市权重（重 ep/lowvol20）；③ **但必须先解决记忆中的 R2 结论**：round73 已实证"regime 不可事前利用"（P5/P20/MA/DD 对 IC 的 ρ 均不显著，P60 段价差 −0.5085）——因此方案②当前**不可行**；④ 在 R2 未破之前，**可行路径是压缩符号翻转维度的权重**，把它们从 0.4244 降到显著更低，代价是牺牲跌市捕获力。 |
| **依据** | `audit_round94.json` `rows.*.up.stat.ic` 与 `verdicts.*.ic_up/ic_down`；`factor_weights.json` 实际权重；记忆 R2（round73）结论。 |
| **预期价值增益** | **高**。可能同时改善分层单调性（C3）与涨市表现。但需明确代价。 |
| **实施难易度** | **低（压缩权重）/ 高（两套权重，因 R2 阻断）**。 |
| **潜在风险** | 压缩防御维度会**直接削弱历史上唯一的真实优势**（跌市 α）。记忆记载"剔 lowvol20 Δα −18.77pp（崩塌）"，因此这是**有代价的取舍**，必须向使用者明示。 |

### P1-2｜把过拟合检测做成流程硬门禁（防 C2 重演）

| 项 | 内容 |
|---|---|
| **现存问题** | round97 从 **16807 个网格**中筛出 210 个可行解，再在这 210 个中挑 minimax 最优——**选择集巨大而验证集仅 19 点**。结果：求解段 `icir_dn=1.1162（t=4.47）` 看似极强，但内部验证段 ICIR **−0.2592**。同期 9 因子等权（**零参数、零选择**）在验证段 ICIR **+1.1419（t=2.66）**。零参数基准全面胜出，是过拟合的经典信号。 |
| **为何重要** | 这是量化研究最危险的失效模式：**流程本身产出的"最优解"系统性优于真实水平**。若不设门禁，每一轮优化都会"找到"一个验证段翻负的解。 |
| **修改方案** | ① 强制并列"**零参数基准**"（等权 / 单因子 / 随机组合）作为对照，任何优化解必须在**同一验证段**击败零参数基准才可进入候选；② 引入**选择自由度惩罚**：记录每轮枚举规模（本轮 16807），要求"验证段提升"不得小于"选择规模对应的期望随机极值"；③ 把"验证段 vs 求解段 ICIR 符号是否一致"设为**硬性断言**，符号翻转即拒绝；④ 重要：`factor_validation_core.py` 的 `feasible()` 与 `combo_ics_at()` 已可复用，只需加断言层。 |
| **依据** | `audit_round97.json`：`n_enumerated=16807`、`n_feasible=210`、`internal_validation` 四项对比（minimax −0.2592 / 全样本最优 −0.2592 / v4.15 −0.0812 / 9因子等权 +1.1419）。 |
| **预期价值增益** | **高**。把"是否过拟合"从人工事后发现（本轮靠我发现）变为流程自动拦截。 |
| **实施难易度** | **低**。均为断言与对照输出，不改核心算法。 |
| **潜在风险** | 门禁趋严后，**可能出现"没有任何方案能通过"的常态**。这是正确的结果，但需要使用者接受"多数迭代不产出可用结论"。 |

### P2-2｜评级双口径的实盘歧义未向使用者说明

| 项 | 内容 |

## 二、四维评估总结

### 2.1 研究严谨性

| 维度 | 现状 | 评级 |
|---|---|---|
| 多重检验校正 | 已用 Bonferroni 3.90（项目累计 304 次检验）+ BH-FDR q=0.10 双档 | **较好** |
| 零参数基准对照 | round97 已并列 9 因子等权 / 单因子 / 5 因子等权 | **较好**（但未设为硬门禁） |
| 过拟合防护 | **缺失**。16807 网格选 210，验证仅 19 点，已验证翻负 | **严重不足**（P1-2） |
| 验证面板保真 | **严重不足**。fund 覆盖率 0% vs 生产 89.58% | **致命**（P0-1） |

| regime 划分 | 明确标注"事后划分，仅诊断不择时" | **诚实，可接受** |

### 2.2 实盘可行性

- **阻塞项**：分层单调性未通过（C3），榜单排序不可直接用于仓位决策 → P0-3
- **阻塞项**：v4.16 候选在验证段翻负（C2），若上线等于引入未验证风险 → P1-2
- **可用项**：线上 v4.15 权重稳定（Σ=1.000000），评级/报告链路完整，日更流程已固化
- **约束项**：42.44% 权重来自符号翻转维度（P1-1），涨市表现结构性偏弱

### 2.3 风险收益特征

| 指标 | 实测值 | 解读 |
|---|---|---|
| 基线期间累计（7 期） | +15.64% | 年化 29.90% 对应 |
| minimax 期间累计 | +28.94% | 年化 58.01% 对应，但验证段翻负 |
| 对 POOL_EW 超额（基线） | **−10.05%**（IR −0.41） | **跑输池等权**，池前视偏差仍未消除 |
| 池等权 vs HS300 | +43.97% vs −2.56%（gap **46.53pp**） | 池选择效应极强，指数超额不可归因 |
| 最大回撤（基线） | −6.85%（组合）/ −20.70%（对 POOL_EW 超额） | 组合抗跌但超额波动大 |

## 三、关键取舍（必须由决策者确认）

1. **是否接受"当前模型不可上线"的结论**：P0-3 严格执行将导致 5 个方案全部不通过。若选择"放宽标准让它通过"，则整个验证流程失去意义。

2. **防御属性是否保留**：P1-1 要求压缩 42.44% 的符号翻转权重，但记忆记载"剔 lowvol20 Δα −18.77pp（崩塌）"。这是"涨市可用"与"跌市抗跌"的**二选一**，不能两全。
