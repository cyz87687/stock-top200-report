## 一、评分模型（v3.6-fund-led 基本面主导 · 2026-10-24 口径切换）

总分按十个维度的加权和计算，再放大 20 倍（每维满分10 / 总分满分100）。

```
现行权重（v3.6-fund-led，池内 IC 积累 ≥30 截面后走步验证再拟合）：
total = ( 基本面×0.34 + 消息面×0.22 + 板块动量×0.10
        + 超跌60反转×0.055 + 乖离低位×0.055 + RSI反转×0.055 + 量能反向×0.055
        + 超买反向×0.02 + 题材内禀×0.08 + 关注度相对×0.02 ) × 20
```

### 为什么从「十维均摊」切到「基本面主导」

v3.1-10dim-ic 把 5 个反转维度合计给了 **34%** 权重，而这 5 维两两相关高达
**0.742~0.889**（`score_bias60|score_rsi_rev`=0.889 最高）——等于把**同一个信号
重复计权 5 次**，同时把真正独立的信号（基本面）压到 18%。切换后的三条依据：

| 依据 | 数据 |
|---|---|
| 全样本唯一通过 Bonferroni 校正的维度 | `score_fund` T+5 IC=+0.0762，NW t=3.48 |
| 剔除共线性虚增后反转块整体降权 | 34% → 22%，且块内**等权**（各 0.055）而非不等权 |
| 小样本维度（<10 截面）不参与主导 | `score_overbought`/`score_attention` 降至 2% 地板 |

**可交易口径回测**（79 截面，t+1 开盘买入/t+h 开盘卖出，扣 20bp 往返）：

| 方案 | h=1 IC | NW t | h=5 IC | NW t | h=20 IC | NW t |
|---|---|---|---|---|---|---|
| v3.1-10dim（旧） | +0.0413 | 2.48 | +0.0560 | 3.38 | +0.0512 | 1.43 |
| **v3.6-fund-led（现）** | **+0.0420** | **2.75** | **+0.0626** | **3.85** | **+0.0645** | **1.73** |

> ⚠️ **诚实披露**：两口径的**逐日配对检验** h=1 配对 t=**0.13**、h=5 配对 t=**1.52**，
> 均未达显著——改善幅度落在噪声范围内。**切换主因是「可解释性与共线性治理」，不是
> 统计显著的超额提升**。权重邻域扫描（67 组，±0.04）显示 h1 t=2.57~2.83、h5 t=3.54~4.03
> 全域稳定，说明不是单点过拟合，但**必须继续用 live IC 验证**。

| 维度 | 权重 | 证据来源 | 该维度证据 | 说明 |
|---|---|---|---|---|
| 基本面 | 0.34 | 池内 IC 已验证（Bonferroni） | T+5 IC +0.0762，NW t=3.48 | 基础分×0.6 + 一阶导(增速)×0.2 + 二阶导(growth−cagr3)×0.2 |
| 消息面 | 0.22 | 池内 IC 已验证 | T+1 IC +0.0441，NW t=2.73 | AI 赋分 0.7×LLM + 0.3×算法，叠加 `day_mod` 当日涨跌绑定 |
| 板块动量 | 0.10 | 池内积累中 | T+1 IC +0.0094（n=18） | 申万二级 60/10 日动量排名（0.6×R60 + 0.4×R10），`--mode evidence` |
| 超跌60反转 | 0.055 | 全市场回测 Top1 | h20 超额 +2.57%，t=7.34 | 60 日收益 ≤−30% 计分；**池内仅 9 截面**，故降至块内等权 |
| 乖离低位 | 0.055 | 全市场回测 Top2 | h20 超额 +2.04%，t=9.40 | 价格相对 MA60 乖离 ≤−15% 计分；池内仅 9 截面 |
| RSI反转 | 0.055 | 全市场回测 Top3 | h20 超额 +1.13%，t=5.21 | RSI14 <30 计分；池内仅 9 截面 |
| 量能反向 | 0.055 | 全市场回测 Top4（负向反向） | h20 超额 −1.31%（反向 +1.31%），\|t\|=12.24 | 放量 2 倍以上记低分；池内仅 9 截面 |
| 超买反向 | 0.02 | 全市场回测 Top5（负向反向） | h20 超额 −0.75% | RSI14 ≥70 计低分；**池内 9 截面且 IC 为负**，降地板 |
| 题材内禀 | 0.08 | 低权重先验 | 池内 h5 IC −0.0499（n=4） | 题材自身强度（AI + 算法融合） |
| 关注度相对 | 0.02 | 先验·弱证据 | 池内 h5 IC −0.0813（n=4） | 成交额排名/换手等关注度代理；**样本不足且为负**，降地板 |

**反转块为何整体降权**：这 5 维在全市场回测（2021-01~2026-09，5019 只 × 1386 日）中
h20 超额 +1.13%~+2.57% 确实有效，但那是**全市场**口径；在本池（成交额 TOP 榜，见下节）
只有 9 个截面可验证、且两两高度共线。设计取舍是：**保留方向、压缩权重、块内等权**，
既不否定全市场证据，也不让未在池内复验的维度主导排序。

**评级**：S≥85 ｜ A 65~85 ｜ B 45~65 ｜ C 25~45 ｜ D <25（绝对分门槛；总分满分 100）

> **prior_pending 纪律（诚实披露）**：新拆维度在 TOP200 池历史截面不足，权重为**先验映射**
> （`factor_weights.json` version=v3.6-fund-led, adopted=prior）；池内截面积累满 30+ 后由
> `factor_eval.py --optimize-weights` 走步验证重拟合，OOS 提升 >0.005 才落档。
> 页面权重块对每维标注证据状态徽章（池内验证 / 积累中 / 先验·待池内验证 / 先验·弱证据）。
>
> **回退先验必须同步**：`step2_stockscorer_v2.py`、`apply_sector_momentum.py`、
> `factor_eval.py`、`enhance_scores.py`、`gen_report_top200.py` 五处各有一份兜底先验常量。
> 改 `factor_weights.json` 时**必须同步这五处**，否则任一脚本读文件失败会静默退回旧口径。
>
> **权重生效规则**：`factor_weights.json` 由 `factor_eval.py --optimize-weights` 生成（走步验证
> 通过才写入），各脚本启动时读取；文件缺失或校验失败自动回退先验。权重变更**自下一次全新
> 评分跑生效**，历史数据的总分仍按当时权重计算（页眉评分层版本以数据自身 model 字段为准）。

> **板块动量赋分方向**：`apply_sector_momentum.py --mode evidence`（默认）依据 2021–2026 回测证据——申万二级板块 R60 与后续 20 日超额呈负单调，故动量末段得分更高；`--mode momentum` 为用户原始思路（动量越强分越高）。

## 一之二、选股池体检（v3.6 新增 · 比权重更根本的问题）

**结论：本池（成交额 TOP 榜）本身是一个系统性负 alpha 集合。**

对 58 个入场日、持有 20 个交易日做「池内 vs 全市场价格池」中位涨跌对照：

| 指标 | 数值 |
|---|---|
| 池内中位超额 | **−5.08 pct**（均值 −8.04 pct） |
| 跑输的入场日占比 | **96.6%**（57/59） |
| 单点验证（06-26 → 10-23） | 池内中位 −43.05% vs 全池 −10.95% |
| 池内跌幅>50% 占比 | 33.2%（全池仅 10.0%） |
| 池内上涨家数 | 9 / 193 |

**归因**：池子按「当日成交额」排序，本质是**高换手关注度脉冲**的集合。脉冲退潮后
系统性回吐——这不是评分模型能修复的。**因子加权再精妙，也只是在这个负 alpha 集合
内部做相对排序**；头组跑赢池均值（+0.03~+1.39pct）仍不等于绝对盈利（头组净收益
−0.81%~−6.46%）。

该体检已接入 `factor_eval.py::_eval_pool_excess`，每日自动计算并写入
`factor_ic.json → pool_excess`，触发阈值时进入 `risk_gate.triggered` 并渲染为页面
「🧺 选股池体检」横幅。**改造入选规则是下一个 P0，调权重已到边际收益递减区间。**

## 二·四、行业数据有效性（v2.46）

**历史问题**：`get_sec()` 原为名称静态字典（348 条），TOP200 中 30~40% 个股未命中而落入
`sector=综合`——题材热度被按中性模板评分、细分题材显示"综合/其他"（如大金重工实为**风电设备**）。
观察池输入自带的 `sector` 是申万二级名（如"化学制药"），THEME_DB 无此键，同样整体落入"综合"模板。

**修复**：以 `sector/sw_map.json`（申万二级，覆盖全市场 5218 只）为**权威源**：

```
resolve_sector(name, code) → (主题键, 申万二级名, 来源)
  ① code → 申万二级行业（sw_map）→ SW2THEME 映射到 THEME_DB 主题键（131 个二级行业全覆盖）
  ② 未命中 → 静态字典兜底 → STATIC2THEME 归一
  ③ 仍未命中 → 综合（语义上确为中性常规赛道：房地产/建筑/环保/贸易等）
```

- THEME_DB 补齐 13 个此前缺失的主题（电力设备/高端制造/航天军工/医药生物/金融/计算机软件/
  交通运输/传媒娱乐/汽车/消费/周期资源/农业/电力）
- 细分题材（`sub_theme`）无 SUB_THEME 条目时**优先展示真实申万二级名**（大金重工 → 风电设备，
  不再显示"综合/Other"；展示层清洗"Ⅱ"后缀）
- 周期股判定（`is_cyclic`）增加申万二级口径 `SW_CYCLICAL`，避免粗分类丢失周期属性
- 结果记录 `sector_src`（sw / static / fallback）供审计

**实测（2026-10-12 数据）**：`综合` 占比 **79 只（41%）→ 6 只（3%）**，189/195 走申万权威映射。

## 二·五、因子有效性评估 · Rank IC（v2.46 → v2.47 口径修正）

`factor_eval.py` 从量化视角衡量"评分因子/推荐"的预测能力，产出 `factor_ic.json`，
报告层渲染「📐 因子有效性评估」区块。

**指标口径**

| 指标 | 定义 |
|---|---|
| Rank IC(t→t+h) | Spearman(因子值在 t 日截面秩, 个股未来 h 个**真实交易日**收益)，h ∈ {1, 5, 20} |
| IC 均值 / 标准差 | 因子平均预测能力 / IC 序列波动 |
| t 统计量 | **Newey-West HAC 调整**（Bartlett 核，lag=h−1）：h=5/20 相邻截面 IC 观测共享 80%/95% 收益窗口，普通 t 把 n 当独立样本会虚高显著性 |
| Bonferroni 校正 | v3.0 起 10 维度 × 3 周期 = 30 次检验，\|NW t\|≥3.08 记为 ★ 显著（旧五维期 15 次检验阈值 2.97，披露备查） |
| IC 胜率 | IC>0 的截面占比（方向一致性） |
| 分层多空 | 每截面按因子分 5 组，头部组均值收益 − 尾部组均值收益（检验单调性） |
| 子区间稳定性 | 半期拆分（前半→后半 IC 均值与方向一致率），检测制度依赖 |
| 因子间相关 | 跨截面平均 Spearman 相关矩阵，披露各维度实际独立信息量 |

**评估对象**：① 十维因子全截面 IC（total / 基本面 / 消息面 / 超跌60 / 乖离 / RSI反转 / 量能反向 /
超买反向 / 题材内禀 / 关注度 / 板块动量，另设旧「题材/技术面」两行对照供趋势比对）
② 推荐组合层 IC（`recommendation_track.json` 中当日推荐的 total 与未来收益）。

**样本与数据来源**：`factor_history.json` 逐日追加紧凑截面快照（约 22KB/日）；
本地首次用 `python3 factor_eval.py --bootstrap-from-git` 从 **git 提交历史**引导
（历史 scored json 虽被 prune 出工作区，但 blob 仍在 git 历史中；Actions checkout 默认
depth=1 无历史，故历史文件随仓库分发）。

**v2.47 口径修正（三大缺陷，修正后结论反转）**：

| 缺陷 | v1 口径问题 | 修正方式 |
|---|---|---|
| 非交易日陈旧快照 | 按快照下标 i+h 假设连续交易日；假日/接口陈旧快照污染索引（09-10 快照价格实为 09-09 旧值） | 快照日期必须是真实交易日（腾讯日线 dates 即交易日序列）；价格与上一快照 ≥80% 相同的判为接口陈旧并剔除（实测剔除 7 个，有效截面 69 个） |
| 留存偏差 | 只对"仍能在 TOP200 找到"的个股算未来收益，跌出榜单即消失（T+20 流失 34% 且非随机） | 回填 **709 只 × 143 个交易日前复权日线**（`--bootstrap-prices`，2 分 23 秒 709/709 成功），收益对 t 日全部 TOP200 个股计算 |
| 重叠窗口 t 虚高 | h=20 相邻观测共享 95% 数据，普通 t 高估显著性 | Newey-West HAC + Bonferroni 双阈值披露 |

修正前后对比（69 有效截面，2026-06-26~10-12）：v1 曾判「综合总分/消息面负向」，
修正后**总分全周期为正**（+0.024/+0.027/+0.053）、**基本面与消息面三周期全正**、
题材（−0.041~−0.094）与技术（−0.035~−0.062）为负向。

**有效性判定规则**：样本 < 20 个截面 → "样本积累中"；否则按 |IC| 与 |NW t| 分档
（显著有效 / 弱有效 / 方向为正·不显著 / 负向·可作反向指标 / 无预测力），
综合判定取 |t| 最大的周期（不同因子有效周期不同，如基本面在 T+20 显著而 T+1 不显著）。

## 二·七、权重优化与数据新鲜度守卫（v2.47 → v3.0）

### 权重优化方法（`factor_eval.py --optimize-weights`）

以 Rank IC 实证反向配置维度权重，核心设计防过拟合：

```
① 仅 IC>0 的维度按 IC 比例分配；IC≤0 的维度降至地板 3%（保留下限维持维度结构）
② 向先验收缩：w = λ·w_IC + (1−λ)·w_prior，λ 由走步验证选择
③ 走步验证：训练窗≥30 截面、每 5 截面重拟；训练窗因子 IC 仅用 T+1 收益完整落在
   训练窗内的观测（max_base_idx 防边界泄漏）；样本外与先验【同日期集合】公平比对
④ 样本外复合 IC 提升 >0.005 才采用，否则维持先验
⑤ score_sector 有效截面<20（2026-09-21 起入库），权重维持 0.10，随积累后评估
```

**v2.47 期优化结果（2026-10-13，69 有效截面，旧五维口径）**：

| 指标 | 先验权重 | IC 驱动权重 |
|---|---|---|
| 消息面 | 0.20 | **0.396**（T+1 IC +0.049） |
| 基本面 | 0.30 | **0.396**（T+1 IC +0.049） |
| 技术面 | 0.20 | **0.044**（T+1 IC −0.035，地板） |
| 题材热度 | 0.18 | **0.044**（T+1 IC −0.041，地板） |
| 板块动量 | 0.12 | 0.12（样本积累中） |

- **样本外走步验证**：复合总分 IC 由 **+0.0248 → +0.0445**（t=2.22，38 个样本外截面，λ=1.0）
- 全周期复合 IC 三周期全部改善：T+1 +0.033→+0.054（NW t 3.44）、T+5 +0.043→+0.075（NW t 3.63）、
  T+20 +0.071→+0.099（NW t 3.08，胜率 80%）
- λ 扫描（0~1.0 共 6 档）单调：0.0248→0.0445，全部 λ≥0.2 均优于先验——"IC 驱动优于先验"的
  结论对 λ 选择不敏感（选择性披露：λ 扫描本身构成对样本外的多次使用，表中样本外值为乐观上界）
- 子区间稳定性：两半期均正向（T+1 +0.056/+0.053，T+20 +0.140/+0.057），无制度切换
- 产出落档 `factor_weights.json`（version=v2.41-ic），step2 / apply_sector_momentum 启动读取

> **为何技术/题材是负向却只降权不删除**：TOP200 是高换手关注度筛选池，负 IC 反映「关注度
> 脉冲后的均值回复」而非因子完全无效；地板 5% 保留下限以维持五维结构与展示完整性。
> 这与独立因子回测工程结论互证（RSI<30 正超额、动量类负 α）。

### v3.5 基本面低基数失真治理（2026-10-14）

**问题**：`score_fund` 的增速 `growth` 取自「扣非净利润同比增长率」**单点值**，当基数极低（接近 0 或为负）
时产生失真极值。池内实证（2026-10-13，490 只）：`growth` 最大 3906%（利通电子）、30 只 >300%；
`growth>150` 的 54 只中 **34 只（63%）三年扣非 CAGR 为负或背离 3 倍以上**。

**双重奖励根因**：① 基础分用 `effective_pe<15 and growth>50` 的**二值闸门**，使 871% 与 55% 都拿满分（等价 bug）；
② `PEG = effective_pe / growth` 分母虚大 → PEG 极小 → 误判「严重低估」再送加分。两者叠加构成**二次奖励**。

**治理**（仅改评分逻辑，**权重未变**，见 `factor_weights.json` 的 `model_logic` 字段）：

| 机制 | 实现 | 说明 |
|---|---|---|
| 增速饱和压缩 | 新增 `_effective_growth(growth, cagr3)` | `growth≤KNEE` 原样；超出时 ceiling＝有正 `cagr3` → `cagr3×2.5+KNEE`，否则硬顶 `CAP`；被压时标 `growth_capped` 并把原始值留档 `growth_raw`（**v3.5.1 起 KNEE=110/CAP=370，按中报口径重标定，见下**） |
| PEG 自动修正 | 无需改码 | `growth` 已重赋为压缩后值，`PEG=pe/growth` 的二次奖励从根源切断 |
| 周期股闸门收紧 | `durable` 判定新增 `_anchor_ok` | `cagr3` 为负（历史衰退）的高增速不再解锁「可持续」，修复中材科技（单点 234% / CAGR −16.5%）、金丹科技（439% / −12.4%）这类**景气峰值幻象** |

**池内影响（2026-10-13 全池 490 只实测）**：17 只（3.5%）基础分变化，基础分最大降幅 0.50 → 总分最大影响 1.80；
评级越档 2 只（光库科技 A→B、凯美特气 B→C）。真实高增长**零误伤**：新易盛 236%、中际旭创 111.3%、
赤峰黄金 79.9%、生益科技 89.5% 全部保留。

**页面可审计**：触发修正的个股在详情卡显示 `📉低基数修正 +871%→+150%` 徽标、完整排名表 PE 列加 `⚠`
（hover 显示原始→采用值）；`factor_weights.json` 的 `version` 同步升为 `v3.5.1-10dim`。

华天科技 +499.8%→+3177.8%（扭亏）、德明利 +120.8%→+4976.0%（扭亏）。

**修复**（`fetch_em_growth_cached()`，东财 `stock_financial_abstract` 按报告期）：

| 项 | 内容 |
|---|---|
| 取数口径 | 各股**最新已披露报告期**（池内 489/490 为 `20260630`）扣非净利润**累计同比**：本期列 ÷ 去年同期列 − 1 |
| 负基数口径 | 官方标准 `(cur−prev)/\|prev\|`（分母取绝对值）——`cur/prev−1` 在负基数下**方向反转**（佰维存储曾被我方误判为 −2963%，老大二次纠错后修正；已用东财自带「归属母公司净利润增长率」字段逐位交叉验证 4/4） |
| 取数优先级 | `growth_src` 留档：东财按报告期(主) > iFinD文本 > 同花顺年报(兜底) > KNOWN；**禁止静默混用** |
| 交叉验证 | 东财自带增长率字段逐位吻合 4/4；全池 6/6 手算复核吻合 |

**参数重标定**（中报口径分布：p50=27.4 / p75=110.8 / p88=372.9，原年报口径 p50≈16 / p75≈71）：

| 参数 | 旧（年报标定） | 新（中报标定） | 被饱和样本 |
|---|---|---|---|
| `GROWTH_SATURATE_KNEE` | 60 | **110**（≈p75） | 105 只(21.4%) → **74 只(15.1%)** |
| `GROWTH_SATURATE_CAP` | 150 | **370**（≈p88） | 真实高增长零误伤（新易盛+90.9/中际旭创+229.3/生益科技+111.0 保留不动） |

**Q3 预测景气加分**（`q3_info` → `score_fund`，上限 **+1.0**，百分制 **+3.6≈+4**，老大拍板）：

- **定位**：Q3 预测**不作为全年盈利预测的直接输入**（表中只有 Q3 单季、无 Q4，直接年化有季节性偏差），
  而作为「景气边际动能确认信号」——**只加分不扣分**
- **去重闸门**（防与 `fwd_np` 双重计价）：`implied_h2 = 机构2026预测净利润 ÷ (H1扣非实际×2) − 1`，
  只有 Q3 同比**超出**该基准才算增量信息。⚠️ `fwd_np` 必须用 `fwd_pe_map` 原始预测净利润，
  **禁止用 `circ_mv`（流通市值）反推**（`pe_ladder` 用总市值算的，低流通股会严重低估——实测雅克科技 ih2 −17.2→+23.8）
- **分档**：强加速 +1.0（accel>0 且 q3_eff≥50 且超 implied_h2+30pt）｜温和 +0.6（≥30 且 +15pt）｜
  略超预期 +0.3（≥+10pt 噪声缓冲）｜扭亏确认 +0.4（文字未量化）｜implied_h2 缺失退化上限 +0.3｜区间颠倒样本减半
- **饱和前置**：Q3 同比**先过 `_effective_growth` 再比对**（普冉 Q3 +3612.6% → 287.2%），防低基数极值触发最高档
- **叠加位置**：持续性封顶**之前**——周期股封顶不被加分突破（兆易创新 +1.0 被 4.5 封顶吸收，审计字段留档）

**数据源与覆盖**：手工汇总表《半导体消费电子三季度预测汇总.xlsx》（105 只）→ `parse_q3_forecast.py`
结构化 → `data/q3_forecast_<date>.json`（TTL 45 天，Q3 实际披露后失效）。池内匹配 **65/490=13.3%**
（精确名称匹配 + 显式别名表白名单，**严禁前缀/模糊匹配**——`比亚迪电子`≠`比亚迪`）。

**报告层披露（Step 5，2026-10-14 已上线，`REPORT_VER`→v3.5.1）**：

### 数据新鲜度守卫（`check_data_fresh.py`，workflow Step 1.5）

| 检查 | 方式 | 失败行为 |
|---|---|---|
| 指数日线日期 | 新浪 `sh000001` 日线最后一根日期 < 北京当日交易日 | exit 2，workflow 重试 3 次后失败（`result=stale_data`） |
| 价格陈旧率 | 新 `top200_all_a.json` 与上一 scored json 快照价格比对，≥80% 相同判为接口陈旧 | exit 3，同上 |

Step 1.5 设为**可重试**（30s×3）：收盘后指数日线偶有几分钟延迟，重试通常恢复；真假日则干净失败，
由 17:30 补偿 cron 或次日任务兜底。

> **已知限制（如实披露）**：守卫采用「数据日期必须 = 运行日期」的严格语义——若 schedule 触发被
> 排队延迟跨午夜（周五 15:30 拖到周六执行），该 run 会被拒而非发布错标报告。代价是延迟跨午夜的
> run 当天缺报（下一个交易日恢复正常）；主触发路径（WorkBuddy 15:40 `workflow_dispatch`）
> 不走 schedule 队列，正常情况不受影响。根治需让全链路按"数据真实日期"标注

## 四、数据纪律

- 所有数字来自真实接口（新浪/腾讯/东财/akshare），**严禁编造**。
- LLM 输出的 `themes[].stocks` 限定在当日 TOP200 在榜名单内，脚本自动清洗名单外个股。
- 生成后抽查模型引用的个股涨跌幅与 scored json 实际值一致性。
- **AI 点评日期校验**：报告只采纳与当日数据日期一致的点评文件（`ai_assessment.json` / 回退文件），日期不匹配则跳过并回退模板文本，防止陈旧点评冒充当日（历史 `ai_review_today.json` 已停用）。
- **本地复盘三态来源标注**：页面点评来源如实区分为「本地复盘（逐公司联网核查）」/「AI 生成」/「规则引擎生成」，并附生成者串可追溯，不得混淆。
- **复盘资料九条校验**（见第二·五节）：code 越界、名称张冠李戴、数值与评分产物不符、无来源
  均判 error 并中止，从机制上阻断编造入库。
- **目标价纪律**：机构目标价仅来自本地复盘逐公司联网核查所得，查不到必须留空（null），
  不得为凑展示而估算；技术目标价由 K 线结构真实推导并标注推导口径。
- **行业归属纪律**：行业以申万二级映射（`sector/sw_map.json`）为权威源，静态字典仅兜底；
  解析来源记入 `sector_src` 供审计，禁止把未匹配个股一律归入"综合"了事。
- **权重纪律**：十维权重只能由 `factor_eval.py --optimize-weights` 经样本外走步验证
  （提升 >0.005）后写入 `factor_weights.json`，禁止手工拍脑袋改权重；新拆维度的先验权重
  依据全市场回测证据映射并如实标注 prior_pending，不得冒充池内验证结论；脚本读取时校验
  字段齐全/非负/Σ≈1，失败自动回退先验。
- **口径诚实纪律**：IC 的 t 值必须 Newey-West HAC 调整 + Bonferroni 校正披露；
  选择性披露（λ 扫描）必须在页面注明；陈旧/非交易日快照必须剔除，不得混入截面。
